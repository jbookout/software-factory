# Input and delivery contract

Prepare JSON outside the public factory checkout. Start from the synthetic `assets/site/presentation.json`, replace the whole dataset and build into a new private output directory. `scripts/build.mjs` validates source/strategy/asset boundaries; `npm run presentation:qualify -- INPUT.json NEW_OUTPUT_DIRECTORY` additionally runs repository checks and browser acceptance before packaging.

The presentation schema is version 2. Configure `brand`, `presentation`, `sections`, `market`, `metrics`, `properties`, `leases`, `developments`, `sources`, `feedback` and optional `currentPractice`/`assumptions`. `strategy.mode` is `owner_occupancy`, `owner_occupancy_30_70` or `lease_only`. Strategy may be visible only in explicit 30/70 mode, with assumptions and bounded TI controls. Full occupancy requires no Strategy view. Empty transaction views are omitted. Stable IDs connect maps, tables, cards, dialogs and selections.

Each property has a name, price or lease rent, area, location, description, planning question, source ID/page, availability and conflicts when known, photo or an explicit missing-photo reason, and source-backed approximate locator or a no-pin reason. `details` can contain additional `{label,value}` facts for the full dialog. Parking unknown stays null. Public corroboration URLs are evidence inputs, not client listing links. Supplied floor plans may be linked. Local assets stay inside the input directory, are copied by content hash and cannot escape through symlinks. Only HTTPS remote URLs are accepted.

`demographics.modelVersion` is 1. One `geography` has `id`, `label`, `kind` (city/county/region/radius); radius research also requires miles and a method. `asOfDate`/`validThrough` are ISO dates. Population has a source, unit `people`, period and increasing calendar-year `{label,value}` counts. Age has period/source, unit `people`, and contiguous lower-inclusive/upper-exclusive labeled cells ending at an open upper bound; it reconciles to the latest population year. Income has period/source, unit `households`, the same cell structure with dollar bounds, explicit median `{label,value,unit:"USD/year",period,sourceId}` and optional threshold bounds that must match a cell's lower bound. Totals, shares, displays and threshold counts are derived. The model does not aggregate overlapping geographic members. Context cards require their own source/geography/period.

Shared selection transport is a destination-owned authenticated same-origin endpoint. GET and successful PUT return `{version,selected_ids,notes,property_notes,updated_at,csrf_token}`. `property_notes` maps selected property IDs to strings of at most 2,000 code points. `notes` is retained for server transport compatibility and has no global client input. PUT sends `{version,selected_ids,notes,property_notes}` with the configurable CSRF header. A 409 returns `{current}` in the same shape. The renderer retains unsaved drafts and requires reload/reconcile before another save. Same-origin paths allow only letters, digits, slash, underscore and hyphen. Disabled feedback uses no endpoint and claims no persistence.

`qualifyPresentation` accepts a destination-owned readback adapter at the hosted-observation seam. Supply the established or requested human-facing HTTPS `clientUrl`; the receipt retains it as `requestedClientUrl`. The adapter receives that URL and its declaration must bind `deployment.status="deployed"`, exact `artifactDigest`, destination `version` and `url` equal to the requested client URL, `hostedAuth` evidence for anonymous denial/authenticated access, and `persistence` evidence for save/reload and conflict. A provider URL cannot substitute for the client portal. The factory never deploys or owns those credentials. Without a readback adapter the receipt records `not_deployed`, `not_checked` authentication and persistence, and `clientReady=false`. The CLI uses this truthful undeployed path.

The receipt carries the renderer version, source commit/tree, input/package digests, producer check receipt and browser results. Unknown, expired, failed or rebound evidence prevents qualification. A portable package includes relative assets and the receipt; hosting and sending remain authorized destination effects. Inspect a separately requested single-file or PDF export independently.

`market.purchaseScreening` optionally supplies practice-screening criteria as `{label,description,sourceId}` records. Each criterion must bind a declared source; the renderer uses these supplied values without inventing client requirements. Home’s demographic snapshot and chart derive from the same model as Demographics. Synthetic presentations remain `clientReady:false` even when a test hosted adapter reports deployment/auth/persistence observations.
